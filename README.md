Site static pentru GitHub Pages.

## Publicare
1. Încarcă `index.html`, `style.css`, `script.js` și `README.md` în rădăcina repository-ului.
2. În GitHub: Settings → Pages.
3. La Build and deployment alege Deploy from a branch, branch `main`, folder `/ (root)`, apoi Save.

Codurile afișate sunt aleatorii și strict demonstrative; nu sunt vouchere sau coduri oficiale.
